# Phase II — Experiment Plan v1.4 (frozen protocol)

**Status:** Protocol frozen before main-data collection; the main experiment was subsequently executed on 10 November 2026. This file records the plan, not a claim that the experiment remains unrun.

## Research questions

**Primary:** Under deterministic decoding, how do three meaning-preserving paraphrases of the same source-only instruction affect the source fidelity and substantive stability of one-sentence scientific conclusions generated by Qwen2.5-0.5B-Instruct and Qwen2.5-1.5B-Instruct when each model receives the same scientific abstract?

**Secondary:** How well does lexical similarity between generated conclusions align with source-grounded judgments of substantive stability?

## Design

- Pathway B: controlled comparative study.
- Dataset: eight publisher-checked scientific abstracts, version v1.1; purposive/convenience sample, not representative of scientific literature.
- Conditions: P0 reference, P1 paraphrase and P2 paraphrase, all applied to the same abstract with common constraints.
- Models: Qwen2.5-0.5B-Instruct and Qwen2.5-1.5B-Instruct, both pinned to recorded revisions.
- Planned and completed output count: 8 × 3 × 2 = 48 generations.
- No training or fine-tuning; train/validation/test splits are not applicable.

## Prompt wording

- P0: “State the central conclusion of the scientific abstract below in exactly one sentence.”
- P1: “In one sentence, report the main conclusion of the scientific abstract below.”
- P2: “Write a single-sentence account of the principal conclusion drawn in the scientific abstract below.”

Common constraints: use only the supplied abstract; do not add external knowledge or invented quantities; preserve important qualifications; return exactly one sentence without commentary.

## Generation settings

Greedy decoding (`do_sample=False`), `max_new_tokens=100`, seed 42 recorded before each generation, and one generation per source × prompt × model condition. Recorded main-run environment: Colab Tesla T4, Python 3.13.16, PyTorch 2.14.1+cu130 and Transformers 5.22.1.

## Evaluation

Each output receives 0, 0.5 or 1 for central-conclusion fidelity, evidential support and preservation of scope/qualifications. The overall output score is their arithmetic mean. Three unordered prompt pairs per source/model are classified as stable, emphasis shift, substantive shift or contradiction. TF-IDF cosine is used only as lexical-overlap analysis. The adapted PSS-style score is a study-specific adaptation inspired by ProSA/PSS, not a full replication of its benchmark.

## Deeper analysis and limitations

Compare lexical similarity with substantive relation judgments and inspect omitted qualifications, unsupported strengthening and format failures. Limitations include the small purposive source set, abstract-only evidence, one model family, one greedy generation per condition and AI-assisted annotations requiring human review. No statistical-significance or broad cross-model claims are supported.
