# Dataset documentation

The experiment uses `study_sources_v1_1_verified.json` (v1.1), containing eight publisher-checked scientific abstracts. The same source abstracts were supplied to both models and all three prompt conditions.

- Dataset SHA-256: `8c2bc1018ee04dc216c55c389ba296c1ad8138566063b1add827ed06d8393295`
- Sample design: purposive/convenience sample; not representative of all scientific literature.
- Scope: abstract-only evidence; full-paper context may be absent.
- Source set: eight abstracts across environmental science, education/public services, health behavior, and software engineering.

## Attribution and reuse

Each record contains the article title, source URL/DOI and available license note. The source register identifies publisher pages and license notes. Before public redistribution, re-check each publisher page and preserve the applicable attribution and license conditions. Do not treat “open access” as automatically meaning unrestricted reuse.

The dataset is included to make the experiment auditable. If a repository maintainer or instructor requires links-only distribution, remove the abstract text files and provide the official source URLs instead.
