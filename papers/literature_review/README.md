# First paper — literature review

This is the first paper that established the research area and motivated the narrower experimental question in the second paper.

- Compiled PDF: `literature_review.pdf` (generated by the repository build workflow).
- LaTeX source and bibliography: `source/literature_review.tex` and `source/references.bib`.
- The prompt-refinement flowchart is embedded as editable TikZ in the LaTeX source, so no external image file is required.

## Rebuild

The workflow `.github/workflows/build-literature-review.yml` compiles the source with LaTeX/BibTeX and commits the generated PDF to this folder. To build locally, run `latexmk -pdf -interaction=nonstopmode -halt-on-error literature_review.tex` from `source/`.

Before final submission, verify all bibliography metadata, confirm that each citation supports the claim it is attached to, and confirm the author/affiliation details.
