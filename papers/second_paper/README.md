# Second research paper — Version 1.4

**Title:** Does Prompt Wording Change Scientific Conclusions? A Controlled Study of Prompt Sensitivity in Instruction-Tuned Language Models.

## Paper files

- `second_research_paper.pdf` — compiled, readable paper (generated by the repository build workflow).
- `second_research_paper.tex` — full LaTeX source.
- `second_paper_references.bib` — BibTeX bibliography.
- `figures/` — the three figures referenced by the manuscript.

## Rebuild

The repository workflow `.github/workflows/build-second-paper.yml` compiles the PDF when the manuscript, bibliography, required figures, or source analysis CSV changes. It also rebuilds `tfidf_by_conclusion_relation.png` from `results/analysis/relation_similarity_summary.csv`.

To build locally from the repository root:

```bash
python scripts/build_second_paper.py
cd papers/second_paper
latexmk -pdf -interaction=nonstopmode -halt-on-error second_research_paper.tex
```

A TeX Live installation with `acmart`, BibTeX, and the paper's font packages is required.

## Important research-integrity note

The paper is an exploratory draft, not a final human-validated submission. It reports 48 main-run outputs. Its 48 output-level quality ratings and 48 pairwise relation labels are AI-assisted first-pass assessments, not independent human ground truth. Review them against the source abstracts before treating the annotations as final. The adapted PSS-style score is study-specific and is not a full replication of ProSA's benchmark. The study makes descriptive, not statistical-significance, claims.
