# Prompt Wording and Scientific Conclusion Stability

A reproducible controlled study of whether meaning-preserving prompt paraphrases change the scientific conclusions generated by instruction-tuned language models from the same scientific abstract. This repository contains the project protocol, dataset, Colab notebooks, raw model outputs, analysis artefacts, AI-assisted manuscript draft and research provenance notes.

> **Research-integrity note:** The main experiment generated 48 outputs. The quality ratings and pairwise conclusion labels are AI-assisted first-pass annotations, not independent human ground truth. They must be reviewed against the original abstracts before final submission.

## Research questions

1. Under deterministic decoding, how do three meaning-preserving paraphrases of the same source-only instruction affect source fidelity and substantive stability of one-sentence scientific conclusions generated by Qwen2.5-0.5B-Instruct and Qwen2.5-1.5B-Instruct from the same abstract?
2. How well does lexical similarity between generated conclusions align with source-grounded judgments of substantive stability?

## Experimental design

| Factor | Conditions |
|---|---|
| Scientific sources | 8 publisher-checked abstracts |
| Prompt wording | P0 reference, P1 paraphrase, P2 paraphrase |
| Models | Qwen2.5-0.5B-Instruct, Qwen2.5-1.5B-Instruct |
| Generation | Greedy decoding (`do_sample=false`), `max_new_tokens=100`, seed 42 recorded before each generation |
| Total | 8 × 3 × 2 = **48 outputs** |

The comparison changes the opening task wording while keeping the supplied abstract, common instructions, output format, model revision and decoding settings fixed within each condition. Both models belong to the same Qwen2.5 family; this is a within-family model-size comparison, not a comparison across independent model families. No model training or fine-tuning was conducted.

### Prompt conditions

- **P0 reference:** “State the central conclusion of the scientific abstract below in exactly one sentence.”
- **P1 paraphrase:** “In one sentence, report the main conclusion of the scientific abstract below.”
- **P2 paraphrase:** “Write a single-sentence account of the principal conclusion drawn in the scientific abstract below.”

The common constraints require use of only the supplied abstract, prohibit invented quantities or external knowledge, require preservation of important qualifications, and request exactly one sentence without extra commentary.

## Quick start

### 1. Inspect the experiment data

The frozen dataset is `data/study_sources_v1_1_verified.json`. Its expected SHA-256 is:

```text
8c2bc1018ee04dc216c55c389ba296c1ad8138566063b1add827ed06d8393295
```

### 2. Validate the recorded 48-output run

From the repository root, run:

```bash
python scripts/validate_experiment_outputs.py
```

The validator checks the frozen dataset hash, expected source/prompt/model combinations, record count, duplicate combinations, empty outputs and recorded model revisions. It does **not** judge whether a generated scientific conclusion is correct.

### 3. Rebuild simple aggregate tables

```bash
python scripts/rebuild_descriptive_summaries.py
```

This rebuilds prompt-wise quality aggregates and pairwise relation counts from the supplied annotation CSVs. It does not reproduce the AI annotation decisions or calculate the original TF-IDF values.

### 4. Rerun the main experiment (optional; requires GPU/Colab)

1. Open `notebooks/02_main_experiment_v1_4.ipynb` in Google Colab.
2. Select a compatible GPU runtime. The recorded main run used a Tesla T4.
3. Upload `data/study_sources_v1_1_verified.json` when prompted.
4. Execute the notebook cells in order.
5. Preserve the generated `main_experiment_raw_outputs_v1_4.json` and CSV as new run evidence. Do not overwrite the archived raw run without versioning it.

The notebook uses pinned Hugging Face model revisions and checkpoints generated outputs. Model downloads require network access and sufficient GPU memory. The recorded main-run environment was Python 3.13.16, PyTorch 2.14.1+cu130 and Transformers 5.22.1. Colab's available package versions can change; check the actual runtime rather than assuming the same environment.

## Recorded descriptive findings

The v1.4 AI-assisted first-pass annotation report records average output-quality scores of 0.618 for Qwen2.5-0.5B and 0.757 for Qwen2.5-1.5B. Across the 48 prompt pairs, it labels 25 stable, 15 emphasis shifts, 8 substantive shifts and 0 contradictions. The average dimension scores were 0.844 for central-conclusion fidelity, 0.719 for evidential support and 0.500 for scope/qualification preservation.

These are descriptive results from a small purposive sample and AI-assisted annotations. They do not establish statistical significance, a general model-size effect, or behavior across all LLMs. See [`results/analysis/analysis_report_v1_4.md`](results/analysis/analysis_report_v1_4.md) for failure cases and limitations.

## Important limitations

- Only eight purposively selected abstracts were used; the sample is not representative of scientific literature.
- Abstract-only inputs may omit context from full papers.
- The two models are from the same Qwen2.5 family.
- One greedy generation was collected per source × prompt × model condition; stochastic run-to-run variation was not measured.
- Three outputs did not follow the one-sentence format and were retained rather than silently edited.
- The output scores and pairwise labels are AI-assisted and still require human review.
- TF-IDF cosine measures lexical overlap, not scientific meaning or truth.
- The PSS-style score is a study-specific adaptation inspired by ProSA/PSS, not a full replication of the published benchmark.
