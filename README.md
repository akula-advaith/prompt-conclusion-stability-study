# Prompt Wording and Scientific Conclusion Stability

A controlled, exploratory study of whether paraphrases of a source-only instruction change the scientific conclusions generated by instruction-tuned language models from the same abstract.

> **Research-integrity note:** The main experiment contains 48 generations. Quality scores and pairwise conclusion labels are AI-assisted first-pass annotations, not independent human ground truth. They must be reviewed against the source abstracts before they are treated as final.

## Research questions

1. Under deterministic decoding, how do three paraphrases of the same source-only instruction affect source fidelity and substantive stability of one-sentence scientific conclusions produced by Qwen2.5-0.5B-Instruct and Qwen2.5-1.5B-Instruct from the same abstract?
2. How well does lexical similarity between generated conclusions align with source-grounded judgments of substantive stability?

## Experimental design

| Factor | Conditions |
|---|---|
| Scientific sources | 8 publisher-checked abstracts |
| Prompt wording | P0 reference, P1 paraphrase, P2 paraphrase |
| Models | Qwen2.5-0.5B-Instruct and Qwen2.5-1.5B-Instruct |
| Generation | Greedy decoding, `max_new_tokens=100`, seed 42 recorded before each generation |
| Main-run size | 8 × 3 × 2 = **48 outputs** |

The source abstract, common constraints, output format, model revision and decoding settings are held fixed within each comparison. The two models are from the same model family; results do not establish a general effect of model size or behavior across other model families. No model training or fine-tuning was conducted.

### Prompt conditions

- **P0:** “State the central conclusion of the scientific abstract below in exactly one sentence.”
- **P1:** “In one sentence, report the main conclusion of the scientific abstract below.”
- **P2:** “Write a single-sentence account of the principal conclusion drawn in the scientific abstract below.”

All conditions share constraints to use only the supplied abstract, avoid external knowledge and invented quantities, preserve important qualifications, and return exactly one sentence.

## Reproducibility

From the repository root:

```bash
python scripts/validate_experiment_outputs.py
python scripts/rebuild_descriptive_summaries.py
```

The validator checks the frozen dataset hash, expected source/prompt/model combinations, record count, duplicate combinations, empty outputs and model revisions. It does not determine whether a generated scientific conclusion is scientifically correct. The summary script rebuilds descriptive aggregates from supplied annotation files; it does not reproduce the AI annotation judgments or the original TF-IDF values.

## Recorded descriptive findings

The first-pass AI-assisted assessment reports mean overall quality scores of 0.618 for Qwen2.5-0.5B and 0.757 for Qwen2.5-1.5B. Across 48 prompt-pair comparisons, 25 were labelled stable, 15 emphasis shifts, 8 substantive shifts and 0 contradictions. The mean quality dimensions were 0.844 for central-conclusion fidelity, 0.719 for evidential support and 0.500 for scope/qualification fidelity.

These are descriptive findings from a small purposive sample and AI-assisted annotations. No statistical-significance or broad generalization claim is made. See `results/analysis/analysis_report_v1_4.md` for details and failure cases.

## Limitations

- Eight purposively selected abstracts are not representative of scientific literature.
- Abstract-only evidence may omit context available in the full papers.
- Both models belong to one model family.
- One greedy generation was collected for each source × prompt × model condition; stochastic variation was not estimated.
- Three outputs failed the one-sentence heuristic and were retained unchanged.
- AI-assisted scores and pairwise labels require human review.
- TF-IDF cosine measures lexical overlap, not scientific meaning or truth.
- The PSS-style quantity is a study-specific adaptation inspired by ProSA/PSS, not a full replication of the published benchmark.
